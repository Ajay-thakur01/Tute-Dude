Selectors in HTML

Element Selector

Element selector targets elements based on their tag name.

Id Selector

Id selector targets elements based on their id attribute.

Class Selector

Class selector targets elements based on their class attribute.

Universal Selector

Universal selector targets all elements on the page.

Direct Child Selector

Direct child selector targets elements that are direct children of a specified parent element.

Descendant Selector

Descendant selector targets elements that are descendants of a specified parent element.
