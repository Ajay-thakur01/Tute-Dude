# ✨ AI Workspace Landing Page

A modern, responsive **AI Workspace landing page** built using **HTML5 and Tailwind CSS**. This project focuses on creating a clean, professional SaaS-style interface for an AI-powered productivity platform.

The design includes a modern navigation bar, hero section, call-to-action buttons, workspace preview, task cards, project status, and activity indicators.

---

## ⚙️ How to Run the Project

### 1. Clone the Repository

Clone the project from GitHub:

```bash
git clone <your-repository-url>
```

Move into the project directory:

```bash
cd Ajay_task22
```

---

### 2. Install Dependencies

The `node_modules` folder is **not included in the GitHub repository**.

After cloning the project, install the required dependencies using:

```bash
npm install
```

This command reads the dependencies from `package.json` and automatically creates the `node_modules` folder.

---

### 3. Start Tailwind CSS

Run the Tailwind CSS CLI in watch mode:

```bash
npx @tailwindcss/cli -i ./style.css -o ./output.css --watch
```

The `--watch` option automatically rebuilds `output.css` whenever you make changes to the project.

Keep this terminal running while developing.

---

### 4. Open the Project

Open `index.html` in your browser.

For a better development experience, you can use the **Live Server** extension in VS Code.

---
